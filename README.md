A 4 KB alpha-beta chess engine in a single `main.py`: quiescence search, transposition table, killer and history move ordering, null-move pruning and late move reductions, at a fixed node budget per move — deterministic, no clock, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8082 python3 main.py
```
